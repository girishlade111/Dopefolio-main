# Dopefolio

Dopefolio — blazing-fast multipage portfolio template for developers.

> Template source in `Dopefolio-main/` ([Demo](https://dopefolio.netlify.app)).

## Features
- Multipage portfolio (home + project pages)
- SCSS (`sass/`) compiled to `css/style.css`
- Responsive, SEO-friendly static HTML

## Getting Started
```bash
cd Dopefolio-main
npm install
npm run build   # prefix + compress CSS
# or open index.html directly
```

Edit `index.html`, `project-1.html`, etc., and styles in `sass/`.

## Tech
- HTML, SCSS, Node-Sass, PostCSS/Autoprefixer
